## Configuració del fitxer .env

En descarregar el projecte, trobaràs un fitxer anomenat ```.env.example```. Aquest fitxer serveix com a __plantilla de configuració__ i conté les variables d'entorn que necessita l'aplicació per funcionar.

Per configurar el projecte al teu entorn local:
1. Crea un nou fitxer anomenat ```.env``` a la mateixa ubicació en la que es troba el ```.env.example```.
2. Copia el contingut de ```.env.example``` a ```.env```
3. Modifica els valors de les variables segons la teva configuració local: ports, usuaris, contrasenyes, adreces, credencials, etc.

Per exemple:
```shell
cp .env.example .ev
```
A continuació, obre el fitxer .env i adapta els valors a les condicions del teu entorn.

>[!IMPORTANT]
>
>**Per què no s'ha de pujar el .env?** el fitxer ```.env``` conté informació sensible i, per tant, __no s'ha de pujar al repositori__. El fitxer ```.env.example```, en canvi, no ha de contenir credencials ni dades sensibles i serveix únicament perquè qualsevol persona pugui saber quines variables necessita configurar
